# 05 · 原始研究筆記

這一區保留去識別化角色稿與 QA correction，讓讀者可以追溯結論如何形成。它不是建議的第一個閱讀入口。

- [`first-round/`](first-round/)：Endocrinology、Hematology、Nuclear Medicine／Surgery 與 Evidence Methods 的第一輪完整 memo。
- [`expanded/`](expanded/)：Case Diagnosis、Drug Safety、Definitive Therapy 與 Publication Methods 的擴充研究稿。
- [`quality-review/`](quality-review/)：交叉審查、原始 PDF 視覺核對與 reconciliation。

這些檔案保留較多研究過程用語，例如角色 ownership、challenge IDs 與已排入佇列／未送達等判讀。公開版刻意不複製 session UUID、native-message JSON、逐字 logs、runner、prompts 或 receipts。文中若提到原 repo 的舊路徑，請使用 [PUBLIC_RELEASE_NOTES](../PUBLIC_RELEASE_NOTES.md) 對照新位置。

若歷史筆記與後續整理不一致，優先順序是：

1. [`../01-case/comprehensive-review.md`](../01-case/comprehensive-review.md)
2. [`quality-review/expanded_reconciliation.md`](quality-review/expanded_reconciliation.md)
3. 主題整理稿
4. 原始角色 memo

早期被更正的數字或用語保留是為了可稽核性，不代表仍是 final conclusion。
