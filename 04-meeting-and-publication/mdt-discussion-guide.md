# 多專科會議主持稿：從不確定資料形成可執行決策

本頁可直接用於 75–90 分鐘 MDT。它以現有個案摘要與文獻為底稿，**不是已舉行真人會議的紀錄**。會議目標是把事實、推論、未解問題、兩條路徑的進入條件及負責人寫成一張可追蹤的決策表。

主要讀物：[完整個案研究](../01-case/comprehensive-review.md)｜[多方專家論點](../02-clinical-topics/expert-consensus.md)｜[投稿評估](case-report-assessment.md)

## 會議結束時必須產生的六項輸出

1. 一份經核對的 Day-relative timeline 與 medication administration record（MAR）。
2. Agranulocytosis、thyrotoxicosis／storm、infection、HFrEF 與 nodules 的診斷確定度。
3. Thyroidectomy 與 I-131 各自的「已滿足／未滿足／不適用」條件。
4. 有時間上限的 bridge plan，含 efficacy、toxicity 與失敗監測。
5. 病人偏好、理解與實際可行性的紀錄。
6. 每個缺件的 owner、deadline、結果回報位置，以及何時重新開會。

## 建議參與者與責任

| 角色 | 會議中要回答的核心問題 |
|---|---|
| Endocrinology | 病因、storm 確定度、hormone trajectory、bridge 與根本治療優先順序 |
| Hematology | Agranulocytosis 嚴重度、recovery、G-CSF 與再暴露禁忌 |
| Infectious Disease／Pulmonology | Pneumonia 的 clinical／microbiologic／radiographic recovery 與程序時機 |
| Cardiology | EF 32% 病因、代償狀態、可逆性、等待期與 perioperative risk |
| Endocrine Surgery | 手術 indication、nodule/pathology 價值、技術風險、可執行中心 |
| Anesthesiology | Airway、cardiopulmonary optimization、monitoring 與 postoperative disposition |
| Nuclear Medicine | Iodine exposure、RAIU readiness、I-131 可行性與 follow-up |
| Pharmacy | 完整 MAR、drug causality、lithium level timing、interaction 與 medication safety record |
| Radiology／Thyroid imaging | 原始 ultrasound、ACR/EU-TIRADS feature、nodes、FNA target |
| Nursing／Case management | Symptom education、follow-up 可達性、照護者與轉診安排 |
| Patient／surrogate | 目標、可接受的等待與風險、對 surgery／radiation／replacement 的偏好 |
| Meeting chair／scribe | 區分 fact／inference／open question，關閉行動項目 |

## 會前資料包

會前至少 24 小時提供下列內容；無資料時清楚標記「未取得」，不要以空白表示正常。

- 去識別化 timeline：症狀、admission、ANC、infection、thyroid labs、cardiac/renal data、iodine exposure、所有 intervention。
- MAR：carbimazole、allopurinol、G-CSF、antibiotics、steroid、Lugol、lithium、beta-blocker、diuretic、contrast。
- CBC/ANC、CRP/culture、oxygen requirement、chest imaging trajectory。
- FT4／FT3／TSH、TRAb assay platform/cutoff、BWPS 的原始同步分項。
- Echocardiography、ECG/rhythm、volume/function、Cr/eGFR、Na/K/Mg。
- 原始 thyroid ultrasound、cervical lymph-node mapping、FNA/cytology（若有）。
- Lugol 配方與最後一劑、所有 iodinated contrast exposure、RAIU／urinary iodine（若有）。
- 病人已接受的說明、偏好及實際追蹤限制。

## 主持原則：每句話要標記層級

會議投影畫面或紀錄建議用以下四個標籤：

- **Fact**：原始紀錄可直接核對，例如 ANC 0、某日 imaging report。
- **Inference**：合理但未被直接證明，例如「thyrotoxicosis 可能造成 cardiomyopathy」。
- **Decision**：團隊基於現有資料選擇的下一步。
- **Open**：缺資料，需指定 owner 與期限。

禁止把 literature case report 的可行性、AI 角色意見或單次 before-after 變化寫成個案事實或因果。

## 建議議程（75–90 分鐘）

| 時間 | 主題 | 主持人要取得的輸出 |
|---:|---|---|
| 0–5 min | 目標與決策問題 | 今天要決定什麼、什麼只做資料補件 |
| 5–15 min | Timeline／MAR reconciliation | 一份共同版本與所有歧異 |
| 15–25 min | Agranulocytosis／drug safety | causality、avoidance record、hematologic recovery |
| 25–35 min | Thyroid diagnosis／storm／nodules | 確定度、病因與影像下一步 |
| 35–45 min | Infection readiness | pneumonia 是否穩定、還差哪些 endpoint |
| 45–55 min | HFrEF／anesthesia | compensated status、reversibility、surgery prerequisites |
| 55–65 min | Bridge／lithium／iodine | 有時間上限的 plan 與 toxicity monitoring |
| 65–75 min | Surgery vs I-131 | 各路徑 readiness 與切換條件 |
| 75–85 min | Patient preference | 病人的理由、可承受性與 informed choice |
| 85–90 min | Close | owners、deadlines、rescue threshold、next review |

## Block 1：Timeline 與 MAR reconciliation

主持問題：

1. Carbimazole 最後一劑是 Day 47 還是 Day 48？症狀開始、CBC 採血及 ANC 確認各是哪一天？
2. Allopurinol 與其他 marrow-toxic drugs 是否真的給藥，起訖與 indication 為何？
3. G-CSF、antibiotics、hydrocortisone、Lugol、lithium、beta-blocker 的 order 與 administration 是否一致？
4. Contrast 注射和 creatinine 採血的分鐘級先後為何？
5. 每一筆 lithium level 距離最後一劑多久；是否為可解讀的 trough？

輸出：一張 timeline、歧異註記與「無法重建」欄位。不能用推測補齊時間。

## Block 2：Agranulocytosis 與 drug attribution

主持問題：

1. Severe agranulocytosis 是否已由 ANC 與症狀確認？recovery 以哪個 endpoint 定義？
2. Carbimazole 的 timing 與 dechallenge 支持度如何？是否有更合理的 competing drug／infection cause？
3. 是否已在 allergy／severe adverse reaction record 清楚標示 thionamide-associated agranulocytosis？
4. 是否有人主張改用 PTU？若是，其依據是否錯把 15.2%、13.8%、32.4%、34.2% 或 50% 的 **all-ADR** 分母當成 agranulocytosis recurrence？
5. G-CSF 的 indication、doses 與觀察到的 recovery 能說到哪裡？

預期結論：一般不以另一種 thionamide 作 routine bridge；因果用「高度懷疑／可能」等與資料相符的語言，不能製造缺資料的 Naranjo 分數。

詳見 [Drug safety and infection](../02-clinical-topics/drug-safety-and-infection.md)。

## Block 3：Thyroid diagnosis、storm 與 nodules

主持問題：

1. Hyperthyroidism 的病因是 Graves、toxic nodular disease、thyroiditis，或仍未定？
2. TRAb 3.00 IU/L 與本檢驗 reference／Graves-specific cutoff 怎麼解讀？
3. BWPS 35→50 的 fever、CNS、GI、heart rate、CHF 與 precipitant 是否來自同一時間點？
4. Infection 與 HFrEF 對 BWPS 的 confounding 如何寫進診斷？
5. 左右 nodules 的 composition、echogenicity、shape、margin、echogenic foci、size、nodes 是否由原圖確認？
6. FNA／cytology 會不會直接改變 surgery 的必要性或 extent？

輸出：problem-list 語言、nodule work-up 與不得越界的診斷敘事。詳見 [Diagnosis](../02-clinical-topics/diagnosis.md)。

## Block 4：Infection readiness

ANC recovery 不等於 pneumonia resolved。請分開回答：

- Clinical：fever、hemodynamics、respiratory symptoms、oxygen need。
- Laboratory／microbiology：culture、inflammatory markers、source control。
- Imaging：necrosis/cavity/effusion 的趨勢；是否符合預期慢速影像恢復。
- Treatment：antibiotic choice、duration、adherence、adverse effects。
- Procedure risk：airway secretion、ventilation、postoperative pulmonary complication 與 timing。

輸出應是「可進入 elective surgery／仍需優化／需 urgent escalation」之一，並附判定依據；不是只寫「infection better」。

## Block 5：HFrEF 與 anesthesia

主持問題：

1. EF 32% 的日期、完整 echo context 與病因評估？
2. Thyroid function／heart rate 改善後是否 repeat echo？
3. 現在是 compensated 還是 decompensated HF？rhythm、volume、BP、functional status 如何？
4. 有無 ischemic、valvular、myocarditis 或其他 cardiomyopathy 需要先處理？
5. GDMT/rate control 的實際使用與 tolerability？
6. 若手術，需 high-volume center、arterial monitoring、ICU/HDU 或其他資源嗎？

輸出：cardiac readiness、優化項目及 anesthesia plan 的需求。詳見 [Cardiac risk](../02-clinical-topics/cardiac-risk.md)。

## Block 6：Lithium 與 bridge safety

主持問題：

1. 住院期間是否確實給過 lithium？FT4 下降前後還有哪些 concurrent interventions？
2. 橋接的明確目標是等待 thyroidectomy、等待 iodine clearance 後 I-131，或 rescue？
3. 預定持續多久；什麼結果表示有效、無效或 toxic？
4. Lithium level 是否在正確時點採血；當時 Cr/eGFR、Na、volume、diuretic、ACEi/ARB/ARNI、NSAID 如何？
5. 若為 I-131 前停 iodide，lithium alone 是否足以支撐，要用哪些 clinical/lab endpoint 判斷？

輸出：agent、goal、duration、monitoring、stop/escalation criteria。不得只寫「continue lithium」。

## Block 9：Patient preference 不可用醫師意向代替

請由病人自己的話記錄：

- 對 surgery、anesthesia、scar、hospitalization 與 complication 的看法。
- 對 I-131、radiation precautions、可能較慢生效與 retreatment 的看法。
- 能否承受停碘等待、頻繁抽血、回診、交通與照護需求。
- 對 lifelong levothyroxine replacement 的理解；兩條路徑都可能造成 hypothyroidism。
- 最重要的生活目標與最不可接受的結果。
- 是否理解 nodule uncertainty 及 surgery 可提供 pathology 的差異。

「病人同意醫師建議」不是充分的 shared decision-making 紀錄；應保存病人選擇的理由與仍有的不確定性。

### 應事先約定的 rescue／switch 類別

- Thyroid：FT4／FT3 反彈、臨床 thyrotoxicosis 惡化、無法維持 bridge。
- Cardiac：new/worsening congestion、unstable arrhythmia、hypotension、ischemic symptoms。
- Infection：fever/hemodynamic decline、oxygen need 增加、new source 或 imaging complication。
- Renal／drug toxicity：Cr、Na 或 neuro/GI symptoms 使 lithium 無法安全持續。
- I-131 readiness：預期時間內 uptake 仍不足或 iodine burden 無法釐清。
- Surgery readiness：infection/cardiac risk 無法降至團隊可管理範圍。
- Patient choice：病人在充分說明後改變偏好。

具體數值 threshold 由 treating team 依病人基線、local protocol 與可用資源填寫；本 repo 不虛構通用 cut-off。

## 會議不應產生的句子

- 「PTU cross-reaction 是 50%，所以一定不能／可以用。」
- 「FT4 在 lithium 後下降，所以 lithium 已證實有效。」
- 「EF 32% 一定不能 surgery。」
- 「I-131 不需要 anesthesia，所以心臟風險最低。」
- 「ANC recovered，所以 pneumonia resolved。」
- 「TRAb 陽性，因此確診 Graves。」
- 「這是 first／unique case。」

這些句子都超過現有資料或證據能支持的範圍。

## 何時重開 MDT

- Repeat echo、RAIU／urinary iodine、FNA/cytology 或關鍵 infection imaging 出現。
- Bridge efficacy 或 toxicity 觸及預設 threshold。
- Primary route 的 prerequisites 無法在期限內完成。
- 病人偏好改變，或追蹤／照護資源發生重大變化。
- 任何急性 cardiac、infectious、thyroid 或 renal deterioration。
