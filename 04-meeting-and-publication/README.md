# 04 · MDT 會議與投稿：把研究轉成決策與可核對稿件

這一區提供三份可直接使用的工作文件。它們分別回答「會議怎麼開」、「資料還缺什麼」與「目前能不能投稿」。

| 文件 | 用途 | 主要輸出 |
|---|---|---|
| [MDT discussion guide](mdt-discussion-guide.md) | 75–90 分鐘多專科會議主持 | Participants、會前資料包、10 個討論 blocks、surgery/I-131 readiness worksheet、patient preference、rescue/switch triggers、owner/deadline 表 |
| [CARE and open questions](care-and-open-questions.md) | 追蹤補件與病例完整度 | 缺件優先序、15 個會改變 treatment 的問題、owner 與 outcome dataset |
| [Case-report assessment](case-report-assessment.md) | 判斷 publication contribution 與時機 | 八組前例比較、可主張界線、稿件形式、標題、結構、圖表、go/revise/no-go gates |

## 目前 publication status

Day 64 以前沒有已執行的 definitive treatment 與長期 outcome。現階段最合適的是去識別化 **case-based teaching analysis** 或 MDT discussion。若要升級為完整 case report，至少需補：

- 實際完成的 thyroidectomy 或 I-131 與後續 thyroid outcome。
- Infection、cardiac、hematologic 與 renal follow-up。
- 經原始紀錄核對的 timeline／MAR。
- Patient perspective、publication consent 與機構／期刊要求。

不要把計畫中的治療寫成已成功完成，也不要用 first／unique 作為主要賣點。相似文獻已分別報告 infection 後 surgery、low EF 後 surgery，以及 lithium bridge to I-131；本案較有價值的重點是兩條路徑同時受限時，如何用可觀察的 readiness gates、病人偏好與 switch criteria 完成決策。

## 建議工作順序

1. 用 [MDT 主持稿](mdt-discussion-guide.md)核對事實並指定 owner。
2. 把未關閉項目登錄在 [CARE 與開放問題](care-and-open-questions.md)。
3. Definitive treatment 與追蹤成熟後，依 [投稿評估](case-report-assessment.md)重新判斷文章形式。
4. 投稿前回到 [Evidence audits](../03-evidence/README.md)，逐一核對百分比、分母、引文與因果語言。

本區是研究與會議工具，不是 clinical order set，也不取代正式 ethics、privacy、consent 或 journal review。
