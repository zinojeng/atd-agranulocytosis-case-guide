# Lithium、停碘、I-131 與 Thyroidectomy

## 1. 先釐清 lithium 是否真的有可歸因效果

FT4 由 Day 48 的 1.61 降至 Day 54 的 1.32、Day 57 的 1.21、Day 59 的 1.13 ng/dL。可確認的 outpatient lithium prescription 是 Day 57；住院期間雖有建議，實際 medication administration 未完整。

因此大部分 hormone decline 已在可確認 outpatient exposure 前發生，而且同時存在 Lugol／KI、glucocorticoid、acute-illness recovery 與其他處置。Day 59 lithium `<0.2` 若不知道服藥幾次、adherence 與採血距前劑時間，不能判定：

- Lithium 無效。
- Dose 不足。
- 病人不可能發生 toxicity。
- 應追求 psychiatry 用的 target range。

需要把 lithium administration、FT4／FT3、Cr／eGFR、Na、volume、diet／fluid changes 與 interacting drugs 放在同一條 timeline。

## 2. 停 iodide 期間能否只用 lithium

「只用 lithium」不是單一固定方案。可行性取決於目前 hormone severity、clinical stability、cardiac reserve、renal handling、drug interactions、預計等待多久與 rescue capacity。

若不能使用 thionamide，可能的 component 包括 beta blockade、short-course glucocorticoid、cholestyramine、lithium，以及極端情況的 therapeutic plasma exchange；每一項都有自己的 contraindications 與監測需求。若 HFrEF 為 low-output／decompensated state，heart-rate control 也不能只套一般門診劑量邏輯。

## 3. Iodine washout：不是只算日曆

本案同時有 water-soluble iodinated contrast 與持續 Lugol exposure。EANM 2023 一般 preparation table 提及 Lugol／SSKI 約 2–3 weeks、water-soluble contrast 約 6–8 weeks，後者有 normal renal function 前提；2026 thyroid-storm consensus 對大量 therapeutic iodide 採更保守的至少 2–3 months 框架。

這是適用情境不同的真實差異，不應任選較短或較長數字。較安全的 readiness 概念是：

1. 確認 contrast 日期與 Lugol formulation、dose、最後一劑。
2. 更新 renal function 與 volume status。
3. 在適當時機使用 urinary iodine 或 RAIU，確認 uptake 是否已回復。
4. 評估 nodules 的 functional status 與 thyroid etiology。
5. 在等待期間設定 hormone／symptom monitoring 與 rescue threshold。

若 uptake 仍低，I-131 的風險不只是「晚一點有效」，也可能是 delivered activity 不足或 treatment failure。

## 4. I-131 五階段路徑

| 階段 | 核心問題 | 必要資料 |
|---|---|---|
| 1. Stabilize | Infection、storm physiology、HF 是否穩定 | Symptoms、vitals、FT4／FT3、infection、cardiac status |
| 2. Reconstruct exposure | Iodine load 到底是多少 | Contrast、Lugol formulation／last dose、renal course |
| 3. Confirm uptake | Thyroid 現在是否能吸收 I-131 | RAIU／scintigraphy、必要時 urinary iodine |
| 4. Treat and bridge | Delayed effect 期間如何避免 rebound | Bridge plan、monitoring、rescue threshold |
| 5. Follow outcome | 是否達到 definitive control | FT4／FT3／TSH、HF、infection、hypothyroidism／replacement |

Vijayakumar 2006 的 122 次 RAI visits 沒有 thyroid storm，但研究排除 complicating intercurrent disease；本案有 pneumonia、HFrEF 與 renal fluctuation，不能直接用「0 event」證明本案安全。

## 5. Thyroidectomy 的條件

優點：

- 快速移除 hormone source。
- 不需等待 iodine uptake 恢復。
- 可同時取得 nodule pathology。
- 可避免 prolonged bridge exposure。

需要處理的風險：

- Necrotizing pneumonia 是否已達 anesthesia／procedure readiness。
- HFrEF 是否 compensated、EF 是否已改善、rhythm／volume 是否穩定。
- 是否需要進一步 nodule／lymph-node workup 影響術式。
- Surgeon experience、airway、bleeding、calcium／recurrent laryngeal nerve risk。
- 術後 lifelong thyroid hormone replacement。

Low EF 並非絕對排除 surgery，已有成功 case reports；但 case report 只能證明做過，不能保證本案 outcome。

## 6. Patient preference 必須真正進入決策

需要詢問並記錄：

- 為什麼偏好 surgery 或 I-131。
- 是否能承受停 iodide、等待 uptake 與 delayed treatment effect。
- 是否接受 anesthesia、scar、hospitalization 與 surgical complications。
- 是否接受 radiation precautions、可能需要 repeat therapy 與後續 hypothyroidism。
- 是否能完成 laboratory、imaging、medication monitoring 與 lifelong replacement。

醫師偏好不能代替病人的理由與可行性。Shared decision-making 的前提是兩條路的可行時間、風險與未知都被清楚說明。
