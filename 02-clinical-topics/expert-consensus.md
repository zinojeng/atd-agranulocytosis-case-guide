# 多方專家論點：共識、分歧與交叉質疑

## 九個角色各自在保護什麼

| 角色 | 核心立場 | 最想補的資料 |
|---|---|---|
| Case Diagnosis | 不把 working diagnosis 寫成確診 | TRAb assay、BWPS 分項、原始 imaging |
| Endocrinology | Bridge 應通往 definitive treatment | FT4／FT3、實際用藥、clinical stability |
| Hematology | 嚴重度已確立，單一藥物歸因未完成 | 完整 MAR、allopurinol、CBC trajectory |
| Drug Safety／Pharmacy | Level 與 dose 必須放回採血、renal、interaction 脈絡 | Lithium administration／timing、Cr、Na、volume |
| Infection／Pulmonology | ANC recovery 不等於 pneumonia clearance | Symptoms、oxygen、imaging、antibiotic course |
| Nuclear Medicine | I-131 readiness 要由 uptake 支持 | Last iodide、urinary iodine、RAIU、renal status |
| Surgery／Anesthesia | Surgery 能快速控制，但 readiness 不只看 FT4 | Infection、repeat echo、airway、nodule workup |
| Cardiology | EF 32% 要重測並重建病因 | Echo、rhythm、volume、functional status |
| Evidence／Publication | 可行性、群體效果與本案因果要分開 | Outcome、patient perspective、consent |

## 已收斂的共識

1. Carbimazole 高度可疑，應避免再暴露；allopurinol exposure 仍需重建。
2. 不應以 15.2%、34% 或 50% 當成本案換 PTU 的 agranulocytosis recurrence probability。
3. ANC、CRP、clinical pneumonia 與 radiographic resolution 是不同終點。
4. 本案 FT4 improvement 不能單獨歸因於 lithium。
5. Surgery 與 I-131 都可以評估，也都有尚未滿足的條件。
6. Contrast 與同日 creatinine 的分鐘級順序不明，不能宣稱 contrast caused AKI。
7. Patient preference 是需要記錄的決策資料，不是附註。
8. 缺 Day 64 後 outcome 時，不宜宣稱 successful bridge 或 first case。

## 尚未完全收斂的問題

### Iodide washout

EANM 一般框架與 2026 thyroid-storm consensus 的較保守建議不同。解法不是任選 2–3 weeks 或 2–3 months，而是重建 exposure、更新 renal function，並用 urinary iodine／RAIU 評估 readiness。

### G-CSF

小型 RCT 未證明明確效果，observational evidence 常見較快 recovery。這是 evidence hierarchy tension；本案不能由三天 ANC recovery 反推出單一藥物效果。

### 先手術還是先等待

沒有單一 EF 或 infection-imaging threshold 能替全體專科做決定。過早 surgery 有 perioperative risk，拖延則有 hormone rebound、bridge toxicity 與 HF deterioration risk。

### Graves 與 nodules

TRAb 在灰區，原始 nodule imaging 不完整。Definitive treatment 選擇前，要釐清病因與 malignancy／functional status 是否會改變路徑。

## 角色之間的交叉問題

- Drug Safety → Diagnosis：BWPS 有多少由 infection 與既有 HF 貢獻？
- Infection → Surgery：CRP decline 足以代表 anesthesia risk 可接受嗎？
- Cardiology → Nuclear Medicine：等待 uptake 恢復期間，心臟能否承受 rebound？
- Nuclear Medicine → Drug Safety：Lithium 是否真的已給，level timing 是否可解讀？
- Surgery → Diagnosis：Nodules 是否提供選擇 thyroidectomy 的額外理由？
- Evidence reviewer → 全體：每個百分比的分母是誰，研究排除了誰？
- Publication reviewer → 全體：病人最後選了什麼，結果如何，是否同意發表？
