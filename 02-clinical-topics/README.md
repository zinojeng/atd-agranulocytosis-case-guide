## 全區共同的五條證據界線

1. **Case report 證明可行先例，不證明成功率或比較優越性。**
2. **Before-after 不能拆出單一藥物效果。** 本案有多項 concurrent interventions。
3. **百分比必須保留 endpoint 與 denominator。** All adverse reactions 不能改寫成 agranulocytosis recurrence。
4. **一次 EF、TRAb 或 lithium level 都需要採檢情境。** 數字不能脫離時間、assay、給藥與器官功能。
5. **Patient preference 是決策資料。** 不能以醫師偏好代替，也不能只記「同意」。

## 本區沒有做的事

本區不提供個人化處方或自行調藥指示；文獻框架不能取代 treating team 的感染、心臟、麻醉、核醫、外科與藥事評估。檔案使用去識別化相對日；公開閱讀也不代表已取得正式 case publication consent。

完整歷史角色稿保留在 [`05-original-research-notes`](../05-original-research-notes/)，便於追查研究過程；新讀者通常先讀本區重寫稿即可。
